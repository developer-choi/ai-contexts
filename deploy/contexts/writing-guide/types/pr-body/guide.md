# pr-body 가이드

## PR 제목

패키지 본문의 H1이 PR 제목이다.

제목은 합의한 `key_message`를 한 줄 길이로 줄이거나 늘려 짓는다. 줄일 때는 `key_message`의 주장을 남기고, 그 주장을 받치는 방법·근거부터 덜어낸다.

- 확인한 결과가 있으면 한 일이 아니라 드러난 것을 담는다
- 명사형 보고체로 끝낸다
- 끝에 마침표를 찍지 않는다
- `feat:` 같은 conventional commit 접두사를 붙이지 않는다
- 공백 포함 60자 이하
- 낱말은 실제 구조에 맞게 고른다 — 공통 패키지를 함께 쓰는데 「서로 공유」라 하는 식으로 구조를 다르게 말하지 않는다
- 사람이 확인한 것을 자동 테스트로 읽히게 하는 「테스트」를 쓰지 않는다
- 명사를 조사 없이 줄줄이 붙이지 않는다

## 넣지 않는 것

- 커밋 목록이나 바꾼 파일·컴포넌트·설정값 나열. GitHub PR 화면(diff)이 이미 보여준다.
- 일반 PR이면 이 PR 밖을 가리키는 다른 PR 번호·브랜치명. 독자는 그 맥락을 볼 수 없다.
