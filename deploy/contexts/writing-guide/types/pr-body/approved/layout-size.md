`````markdown
# 통일성을 위해 로고 크기를 2종류로 제한

로고 크기를 화면마다 숫자로 따로 정하고 있어서, 오류 안내는 64px, 파비콘은 32px이었습니다. 로고가 들어갈 화면이 늘수록 크기 가짓수도 함께 늘어납니다.

| 종류 | 크기 | 쓰는 곳 |
|---|---|---|
| `medium` | 32px | 파비콘, 소개 페이지(이 PR 이후) |
| `large` | 52px | 오류 안내, 로그인 화면(이 PR 이후), 첫 기록 화면(이 PR 이후) |

그래서 크기를 2종류로 제한했습니다.
`````
