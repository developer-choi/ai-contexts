`````markdown
# 통계 화면에서 직관적이지 않던 UI 네 곳 개선

통계 화면을 처음 본 디자이너가 잘못 읽은 네 곳을 고쳤습니다.

## 진행 중인 달

진행 중인 달 막대는 빗금으로만 구분해서, 덜 찬 막대가 "이번 달 실패가 줄었다"로 읽힐 수 있었습니다. 막대 아래에 "진행 중" 라벨을 달았습니다.

## 태그 달력

범례 없이 칸 모양이 넷이라 모양마다 무슨 뜻인지 헷갈렸습니다. 칸을 해당 태그를 적은 날(빨강)과 나머지(회색) 두 가지로 줄였습니다.

## 시간 표기

화면에서 누적 공부는 "2시간", 평균은 "2:45"로 표기가 달라 기록이 잘못 저장된 것처럼 보였습니다. 통계 안의 시간을 모두 "N시간 M분"으로 맞췄습니다.

## n월 기록

기록 카드의 `19 / 30일`에서 분모가 무엇을 세는지 알아보지 못했습니다. 분모를 빼고 "남기지 못한 날이 11일 있어요" 같은 문장으로 바꿨습니다.
`````
