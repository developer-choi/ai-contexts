`````markdown
# 로그인 전후로 원래 가려던 페이지로 가지 못하던 버그 2건 수정

로그인이 필요한 페이지에 로그아웃 상태로 들어오면 로그인 페이지로 보내고, 로그인이 끝나면 원래 가려던 페이지로 돌려보냅니다. 그런데 아래 첫 주소로 들어오면 제대로 돌아왔지만, 나머지 두 주소로 들어오면 원래 가려던 페이지로 가지 못했습니다.

- `/studied-time` → 로그인 후 `/studied-time`으로 돌아옴 (정상)
- `/studied-time-old` → 로그인이 필요 없는데 로그인 페이지로 감
- `/studied-time?a=1&b=2` → 로그인 후 `/studied-time?a=1`로 돌아옴

원인은 아래 두 가지였습니다.

## `/studied-time`과 앞부분만 같은 경로는 로그인 없이 바로 들어감

로그인이 필요한 경로인지를 `startsWith`로 판정해서, `/studied-time-old`처럼 앞부분만 같은 경로도 로그인 페이지로 보냈습니다.

- `/studied-time/2026/10` (하위 경로) → 수정 전후 모두 로그인 페이지로 감
- `/studied-time-old` → 수정 전: 로그인 페이지로 감 / 수정 후: 로그인 없이 바로 들어감

## 쿼리가 여러 개여도 로그인 후 그대로 복귀

`/studied-time?a=1&b=2`로 들어왔으면 로그인 후 `/studied-time?a=1&b=2`로 돌아가야 하는데, `/studied-time?a=1`로 돌아왔습니다. 원래 주소를 인코딩하지 않고 `redirect` 쿼리에 붙여서, `b=2`가 `redirect` 값이 아닌 로그인 페이지 주소의 별도 쿼리로 읽혔기 때문입니다.

이제는 로그인 후 `b=2`까지 붙은 원래 주소로 돌아옵니다.
`````
