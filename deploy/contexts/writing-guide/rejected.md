# rejected

어느 레포의 어떤 글에서든 앞으로 쓰는 모든 글에 걸도록 사용자가 반려한 낱말·문구는 같은 폴더 `rejected.json`에 쌓습니다.

목록은 스크립트만 읽습니다 — 쌓일수록 모든 회차의 맥락이 늘어나기 때문입니다. 스크립트는 본문에 걸린 자리를 대신 쓸 말과 함께 냅니다.

## 항목 꼴

```json
{
  "lane": "수정필요",
  "words": ["<표현>", "<활용형>"],
  "instead": ["<대신 쓸 말>", "<그 활용형>"],
  "evidence": [{ "date": "2026-10-13", "said": "<근거 발화 원문>" }]
}
```

- **lane**: 글을 게시할 때 그 표현이 남았으면 게시를 막을지, 알리기만 할지를 정합니다.
  - `항상금지`: 낱말 자체가 틀린 것.
  - `수정필요`: 쓰임에 따라 맞기도 한 것. 쓰임을 봐야 갈리는 표현을 항상금지에 넣으면, 채점기 적발을 0건으로 맞추려고 멀쩡한 문장을 깎습니다.
- **words**: 본문에서 그대로 찾는 글자입니다. 더 긴 낱말 속에 든 글자도 잡습니다.
  - 활용형은 저절로 늘리지 않으니 잡을 꼴을 하나씩 적습니다.
  - 글자로 찾을 수 없는 반려(절 구성·말투)는 여기 넣지 않고 [map.md 「역할」](map.md#역할)이 정한 자리에 규칙으로 둡니다.
- **instead**: 배열이면 words와 꼴마다 짝지어 내고, 짝이 안 맞으면 문자열 하나(`<A> 또는 <B>`·고치는 법)로 적습니다.
- **evidence**: `said`에 발화 원문을, 원문을 못 구하면 `source`에 어디서 왔는지 적습니다. 지어낸 발화를 넣지 않습니다.
