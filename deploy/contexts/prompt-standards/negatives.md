# negatives.mjs 사용법

`node <ai-contexts 배포 폴더>/contexts/prompt-standards/negatives.mjs <대상.md> [<대상.md> …]`

대상 md마다 부정문이 든 문장을 바로 앞뒤 문장과 함께 stdout에 출력한다. 부정문은 "않는다"·"못한다"·"아니다"·"말고"·"금지"·"없이" 류이고 습니다체도 포함한다. 남길지 지울지는 판정하지 않는다. 옵션은 없다.

- 코드블록(```` ``` ````·`~~~`) 안은 건너뛴다
- 앞뒤 문장은 같은 줄이나 바로 이웃한 줄에서 찾고, 빈 줄·헤딩은 넘지 않는다

## 출력

```
## <대상.md> — 부정문 N개

- <줄 번호>: <부정문>
  - 앞: <앞 문장>
  - 뒤: <뒤 문장>
```

앞이나 뒤 문장이 없으면 그 줄은 빠진다. 뽑힌 줄마다 판정한다.

## 실패

- 대상 경로가 없으면 사유와 이 문서 경로를 stderr에 출력하고 exit 1
- 대상 파일을 못 읽으면 Node 오류로 exit 1
