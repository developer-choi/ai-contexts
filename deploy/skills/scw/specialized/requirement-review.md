# requirement-review 특화 체크리스트

`skills/workflow/requirement-review/` 리뷰 시 추가로 점검하는 항목.

## 배경

SKILL.md는 모드(입력 타입)별 가이드가 채우는 **슬롯**만 정의하고, 실제 내용은 모드마다 따로 산다. 그래서 모드가 갈리는 자리에서 정합이 깨진다 — 어떤 모드는 산출물 양식이 있고 어떤 모드는 없으며, 점검 항목 파일도 모드마다 있고 없다.

## 특화 항목

### 점검 항목 → 가이드 참조 정합성

점검 항목 파일이 그 모드의 가이드에서 실제로 소비되는지 확인한다. 가이드가 폴더 단위로 참조하고 있으면 그 폴더 안 파일은 모두 살아있는 것으로 본다 — 개별 파일명이 어딘가에 호명되기를 요구하지 않는다.

죽은 문서 후보는 **어느 가이드의 어느 슬롯도 그 폴더를 안 가리키는 경우**다.

### 관심사 ↔ 페이지 특성 분리

checklist/ 하위 파일이 관심사(모든 페이지 공통)와 페이지 특성(특정 유형에만 해당)을 혼재하고 있지 않은지 확인한다.

- 관심사 파일(flow.md, data.md 등)에 특정 페이지 유형에만 해당하는 항목이 섞여 있지 않은지
- 페이지 특성 파일(page-type/)이 있다면, 관심사 파일과 내용이 중복되지 않는지
