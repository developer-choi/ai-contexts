# Writing-Guide 특화 체크리스트

`contexts/writing-guide/` 리뷰 시 추가로 점검하는 항목. 탐색 절차는 `map.md` 참조(Glob + 각 파일 frontmatter `tags` 기반, 수기 목록 없음).

## [CRITICAL] 분류 검증

다른 문서가 역할 기준으로 파일을 참조하므로, 분류가 틀리면 규칙 누락이나 잘못된 로드가 발생한다. 종류 정의는 `map.md` 「역할」이 정본이다.

- 각 파일이 어느 종류인지 판정한다. 한 파일에 여러 종류가 섞여 있으면 분리를 검토한다.
- **정의에 안 걸리는 파일이 나오면 그 파일이 아니라 정의를 의심한다.** 문안 프리셋(`templates/` 하위)처럼 세 종류 어디에도 안 들어가는 자산이 이미 있다. 매번 "미분류"로 잡히는 파일은 분류가 현행 폴더를 못 덮는다는 신호이고, 그때 고칠 곳은 `map.md`다.

## 규칙-사례 연결성 검증

- 사례(`examples/` 하위 전부)에 관련 규칙 태그가 있는지
- 규칙에 대응하는 사례가 있는지 (없어도 에러는 아니나, 커버리지 파악)
