# Skill 오케스트레이션 특화 체크리스트

`SKILL.md` 또는 sub-skill의 본 라우터 파일 리뷰 시 추가로 점검하는 항목.

## SKILL.md가 담당할 것

[스킬 짜임](../../../contexts/prompt-standards/skill-structure.md#skillmd는-안내만-한다)으로 본다. 폴더 구조를 그려 두면 그것이 낡는 것은 [손으로 유지되는 지도의 문제](../../../contexts/prompt-standards/file-layout.md#손으로-유지되는-구조-지도는-썩어도-아무-검사에-안-걸린다)로 다룬다 — 두지 말라는 것이 아니라, 두는 쪽이 무엇으로 안 썩게 할지를 함께 정한다.

## sub 흐름 파일의 번호·내부 구조를 가리키는 자리

다른 파일의 번호나 sub 흐름 내부 구조를 가리키는 자리는 [다른 파일의 번호·내부 구조는 역할 이름으로](../../../contexts/prompt-standards/sources-and-links.md#다른-파일의-번호내부-구조는-역할-이름으로-부른다) 본다.
