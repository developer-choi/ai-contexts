# 순차 플로우

여러 단계를 순서대로 거치는 플로우의 각 단계 페이지에 추가 적용한다. (온보딩, 회원가입 단계 등)

일반적인 이탈·복귀는 [planning/cross-page.md](../planning/cross-page.md)의 범위다. 여기서는 **단계가 있어서 생기는 것**만 묻는다.

## 네비게이션

- 다음 단계로 넘어간 뒤 뒤로가기하면 이전 단계로 돌아가는가?
- 앞 단계 데이터 없이 중간 단계에 들어오면 어떻게 되는가?

## 이탈/복귀

- 새로고침하면 현재 단계까지 입력한 데이터가 남는가?
- 다시 들어오면 마지막으로 마친 단계부터 이어지는가?
