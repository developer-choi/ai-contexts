# 기획서 리뷰 가이드

## 맥락 수집

- 이 서비스가 무엇을 하는 서비스인지
- 이번에 리뷰할 기능이 무엇인지 (한 줄 요약)
- 신규 서비스/기능인지, 기존 기능 개선인지
- 알아두어야 할 배경이나 제약사항이 있는지

## 입력 자료

페이지 단위의 기획서 자료.

## 체크리스트

`checklist/` 하위 파일을 적용한다.

## 산출물

- `/plan/background/consumable/global.md` — 전체 서비스 맥락, 공통 컴포넌트
- `page.md` — 페이지별 분석 결과 (위치·이동은 [conventions/plan-folder.md](../../conventions/plan-folder.md))

## 같이 분석

1. 템플릿의 각 섹션을 자료에서 파악한 내용으로 채운다.
2. 채팅에 모호하거나 빠진 정의·엣지케이스·(있으면) UX 대안을 나열한다.
