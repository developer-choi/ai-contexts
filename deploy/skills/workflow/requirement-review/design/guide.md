# 디자인 시안 리뷰 가이드

## 맥락 수집

- 디자인 시스템이나 스타일 가이드가 있는지
- 반응형 범위

## 입력 자료

페이지 단위의 디자인 시안 자료.

## 체크리스트

페이지마다 [페이지 체크리스트](./checklist/page.md)를, 그 페이지에서 새로 만들 컴포넌트마다 [컴포넌트 체크리스트](./checklist/component.md)를 적용하고, [공통 체크리스트](./checklist/common.md)는 둘 다에 적용한다.

## 산출물

- `/plan/background/consumable/global.md` — 공통 컴포넌트(구조 관찰)·반응형 정책
- `page.md` — 위치·이동은 [conventions/plan-folder.md](../../conventions/plan-folder.md)

체크리스트 결과는 컴포넌트에 걸리면 「구조 관찰」, 로딩·에러 UI는 「API 목록」의 해당 API 항목, 빈 상태 UI와 이 페이지의 반응형 차이는 「페이지 동작」에 적는다.

## 같이 분석

1. 체크리스트 항목마다 자료에서 확인한 내용을 「산출물」이 정한 칸에 적는다.
2. 채팅에 발견한 문제(이미 적힌 page.md 내용과 자료가 어긋나는 곳 포함)를 나열한다.

## 종합 관점

페이지 간 어긋난 디자인 패턴(패턴·해당 페이지).
