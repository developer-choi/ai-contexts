# 페이지 전용 디자인 점검 항목

> 상태가 **있는지**는 기획 체크리스트가 점검한다. 여기서는 그 상태가 **어떤 화면으로 그려졌는지**를 점검한다.

## 1. 로딩 UI

- 로딩 UI가 페이지 전체 단위인가, 섹션 단위인가?
- 스켈레톤 UI가 있는가? 있다면 어떤 형태인가?
- 로딩 중 사용자가 조작할 수 있는 영역이 있는가?

## 2. 에러 UI

- 페이지 전체 에러 화면이 있는가?
- 특정 섹션만 에러일 때의 화면이 있는가?
- 재시도 버튼/액션이 포함되어 있는가?

## 3. 빈 상태 UI

- 데이터 0건·검색 결과 0건일 때의 화면이 있는가? 있다면 안내 문구와 다음 행동 버튼이 있는가?

## 4. 반응형

해당 페이지가 프로젝트 반응형 정책과 **다른 점**이 있는지만 확인한다.

- 이 페이지에만 정책에 없는 화면 크기 대응이 있는가?
- 특정 요소가 화면 크기에 따라 숨겨지거나 재배치되는가?
