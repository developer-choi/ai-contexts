# 자유 검토

체크리스트와 무관하게 리뷰 대상 자료를 처음부터 다시 보고, 체크리스트가 잡지 못한 문제를 찾는다.

- 체크리스트 항목에 해당하지 않지만 기획/구현상 문제가 있는 부분이 있는지
- 체크리스트가 다루지 않는 관점(사업적 맥락, 기술 부채, 타 기능과의 충돌, 디자인 시스템 일관성, 접근성 등)에서 문제가 없는지

산출물을 쓴 메인은 직접 훑지 않고 일회성 서브에이전트에 맡긴다. 원본 자료 경로, 모든 page.md·global.md 경로(recruitment만 켰으면 todo.md 경로), 이 파일을 넘기고, 문제마다 넣을 곳과 근거 원문만 돌려받는다. 코드기반 모드면 서브에이전트는 코드에 물을 것을 질문 목록으로 함께 돌려주고, 메인이 코드 읽기 팀원에게 물어 받은 답으로 해당 여부를 가린다.

찾은 문제는 해당 페이지의 page.md(여러 페이지에 걸치면 global.md, recruitment만 켰으면 todo.md)에 반영하고, 무엇을 찾아 어디에 넣었는지 사용자에게 보고한다.
