# 자유 검토

리뷰 대상 자료를 처음부터 다시 보고, 가이드의 체크리스트·분석 과정이 잡지 못한 문제를 찾는다.

산출물을 쓴 메인은 자유 검토를 일회성 서브에이전트에 맡긴다.
원본 자료(`background/`) 경로, requirement-review가 쓴 산출물 경로 전부(PR 폴더로 옮겨진 page.md까지, [위치](../conventions/plan-folder.md)), 켠 플래그의 가이드 경로, 이 파일을 넘기고, 문제마다 넣을 곳과 근거 원문만 돌려받는다. 넣을 곳은 각 가이드의 「산출물」·「분석 과정」이 정한 대로 고른다.
코드기반 모드면 서브에이전트는 코드에 물을 것을 질문 목록으로 함께 돌려주고, 메인이 코드 읽기 팀원에게 물어 받은 답으로 해당 여부를 가린다.

메인은 돌려받은 문제와 넣을 곳을 사용자에게 보고하고, 사용자가 고른 것만 반영한다.
