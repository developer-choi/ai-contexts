# 자유 검토

리뷰 대상 자료를 처음부터 다시 보고, 체크리스트와 리뷰 절차가 잡지 못한 문제를 찾는다.

산출물을 쓴 메인은 자유 검토를 일회성 서브에이전트에 맡긴다.
`node {{skill_dir}}/scripts/plan-folder.mjs requirement-files`가 낸 경로 전부, 이번에 돈 step 파일, SKILL.md, 이 파일을 넘기고, 문제마다 넣을 곳과 근거 원문만 돌려받는다. 넣을 곳은 채용과제 분석 step의 [산출물](recruitment/step.md#산출물)과 페이지 리뷰 step의 [같이 분석](page-review.md#2-같이-분석) 2가 정한 대로 고른다.
[코드 대용](page-review.md#준비)이면 서브에이전트는 code-target.md가 적은 코드를 읽는 대신 코드에 물을 것을 질문 목록으로 함께 돌려주고, 메인이 코드 읽기 팀원에게 물어 받은 답으로 해당 여부를 가린다.

메인은 돌려받은 문제와 넣을 곳을 사용자에게 보고하고, 사용자가 고른 것만 반영한다.
