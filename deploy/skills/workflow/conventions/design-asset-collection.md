# 시안·기획 자료 수집 가이드

시안·기획서를 받기 전 또는 받은 직후에 이 가이드대로 자료가 준비되어 있는지 점검한다.

## 권장 매체 매핑

| 정보 종류 | 매체 |
|---|---|
| validation 규칙·정확한 텍스트 | Figma 텍스트 복사 (이미지 X) |
| description 박스 | Figma 텍스트 복사 |
| 컬럼명·라벨·enum 한글 매핑 | Figma 텍스트 복사 |
| 레이아웃·컴포넌트 형태 | Figma export 2x PNG |
| 모달·에러·별도 화면 | Figma export 2x PNG (의미 단위 별도) |

핵심: **텍스트 정보는 텍스트로, 레이아웃은 이미지로**.

## 받기 전 안내

사용자가 시안을 아직 받지 않은 상태면 모델이 위 매핑을 능동적으로 안내한다.

## 이미 받은 후 점검

자료가 이미 들어와 있으면, 흐린 영역·식별 어려운 텍스트를 구체적으로 짚어 다시 요청한다. 추측으로 진행 금지.
