# 부정 명시 메아리 자가 점검 — 찾는 갈래

[SKILL.md](../SKILL.md) 「부정 명시 메아리 자가 점검」 절차의 step 1에서 사용한다. 산출물 텍스트에서 부정 표현이 등장하는 라인을 아래 세 갈래로 찾고, 걸리면 분류 단계로 넘어간다.

## 찾는 갈래

- **사용자 부정 지시의 메아리** — 사용자가 부정한 것을 산출물에 부재·부정으로 다시 적은 것. 형식 불문 — 본문 서술이든, 인용 블록·"사용자 발화" 섹션이든, "이번 PR 범위 외"·"후속 단계 예정" 같은 스코프 선언이든 모두 해당한다. 인용이라고 면제되지 않는다 — 사용자는 자기 발화를 안다. 결정의 채택안과 근거만 적는다.
- **거부된 대안의 흔적** — 사용자가 부정한 라이브러리·패턴·도구를 "검토했다"·"초안"·"기각한 대안"·"A vs B 비교" 같은 과거 행위 서술로 남긴 것. 사용자가 "X 쓰지 마"라고 했으면 X는 산출물 어디에도 등장하지 않아야 한다.
- **근거 없는 부재 선언** — 자체 판단으로 무언가를 안 했다고 적었는데 근거가 붙어 있지 않은 것.

## 분류 가이드 (step 2 보조)

### 사용자 메아리 판정

사용자 발화의 부정 지시(`negative_directives`로 식별)와 산출물의 부정 표현이 의미적으로 매칭되면 **사용자 메아리**.

### 근거 동반 판정

같은 문장 또는 즉시 인접 라인(±1)에 다음 중 하나가 명시되어 있으면 **근거 동반**:

- 측정값·수치
- 기존 코드베이스·패턴 참조
- BG 단계 결정 인용
- 충돌 지점 명시

근거가 없거나 일반론적 진술("성능 트레이드오프")만 있으면 **근거 없음**.
