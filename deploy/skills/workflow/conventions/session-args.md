# 세션 인자 확정 (BG)

BG는 requirement를 시작하기 전에 이 절차로 모드·접두어·plan 경로를 확정한다. 값 하나가 틀리면 그 작업 묶음의 후속 세션 이름과 plan이 전부 따라 틀리므로, 값은 AI가 작업 내용을 보고 짓지 않는다.

1. 접두어 후보를 정한다. 호출에 `--prefix`가 있으면 그 값, 없고 Claude Code 세션 이름(`/rename`으로 붙인 이름)이 `<X>_BG` 꼴이면 X, 둘 다 없으면 후보 없음이다.
2. 받은 모드와 후보로 `node {{skill_dir}}/scripts/steps.mjs start BG --mode <모드> [--prefix <후보>] [--plan <받은 plan 경로>]`를 먼저 돌린다. 실패해도 메인 레포 루트·plan·빠진 값이 찍힌다.
3. 찍힌 값으로 모드·접두어·plan·메인 레포 루트를 한 번에 보여 주고 확인받는다. 하나씩 묻지 않는다.
   - 모드는 호출에서 받은 값이다. 호출에 없으면 제안 없이 묻는다
   - 접두어 후보가 없으면 제안 없이 묻는다. 개인 모드는 필수, 실무·채용은 비워도 된다
   - 메인 레포 루트가 대상 레포가 아니면(다른 폴더에서 띄웠으면) 여기서 멈춘다. 루트는 인자로 고칠 수 없어서, 대상 레포 루트에서 세션을 다시 띄우거나 plan을 드라이브까지 적은 절대경로 `--plan`으로 받는다
4. 사용자가 고친 값이 있으면 고친 값으로 `start BG`를 다시 돌린다. 통과할 때까지 반복한다.
5. 이후 `next`와 plan을 받는 도구 호출에는 `start`가 찍은 값을 그대로 쓴다. 통과 뒤 접두어를 바꾸면 plan 폴더를 새 이름으로 옮기고 `start BG`를 다시 돌린 뒤, 이미 안내한 실행 명령이 있으면 새 값으로 다시 안내한다 — 개인 모드 plan이 `plan/<접두어>`라 폴더를 안 옮기면 그동안의 산출물이 옛 폴더에 남는다.
