# PR Comment Respond

내 PR에 달린 리뷰 코멘트를 분석하고, 코드 수정과 답글 작성까지 마무리하는 스킬입니다.

## 동기

코멘트를 받으면 단순히 고치는 것보다 중요한 게 있습니다. 내가 몰라서 틀린 건지, 실수한 건지, 의견 차이인지에 따라 대응이 달라집니다.

이 스킬은 코멘트를 네 가지로 분류합니다.

- **모르는 것**: 공식문서 등으로 학습이 필요합니다
- **실수/오류**: 같은 실수를 다시 하지 않을 방법이 필요합니다
- **의견 차이**: 양쪽 근거를 정리하고 받아들일지 반박할지 정합니다
- **단순 수정**: 바로 고칩니다

분류한 결과는 먼저 보여드리고 확인을 받은 뒤에 대응을 시작합니다. 어떤 코멘트를 어느 쪽으로 봤는지 제가 직접 판단할 수 있어야 하기 때문입니다.

모르는 것은 학습한 뒤 어디에 기록해둘지 정합니다.

실수는 왜 생겼는지 원인을 짚고, 어떤 규칙을 보완하면 되는지 메모로 남깁니다. 같은 코멘트를 두 번 받지 않기 위해서입니다.

지적받은 것이 그 한 줄에만 있는 문제인지, 같은 습관이 반복된 문제인지도 가립니다. 반복된 것이면 PR 안 다른 곳도 찾아 함께 고칩니다.

의견 차이로 분류한 것은 제가 받아들이기로 정한 뒤에만 다른 곳을 찾습니다. 아직 결론이 안 난 지적을 코드 전체에 미리 적용하지 않기 위해서입니다.

답글이 필요한 코멘트는 리뷰어가 읽을 답글까지 작성합니다.

마지막으로, 고친 코드가 다른 곳에 영향을 주지 않는지 전체를 점검합니다. 한 곳을 고쳤더니 다른 데가 문제되는 일을 막기 위해서입니다.
