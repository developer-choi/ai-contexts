# 결정 기록 발췌

결정 기록은 메인이 열지 않는다(Read·`cat`·Grep 모두).
메인은 일회성 서브에이전트(sonnet)에 결정 기록 경로, diff, 메인이 정한 임시 파일 경로를 넘긴다. 서브에이전트는 이 diff에 닿는 줄만 `파일:줄`과 원문으로 뽑아 그 임시 파일에 적는다. 닿는지 애매하면 뽑는다. 줄 번호는 Read 출력의 번호를 그대로 적게 한다.
메인은 그 임시 파일도 열지 않고, 경로를 리뷰어 지시문에 넣는다.

리뷰어가 「사용자 결정이라 다름」으로 뺀 차이 중 결정 기록 근거(`파일:줄`과 원문)가 붙지 않은 것은, 호출 프롬프트가 빼라고 해도 메인이 이슈 목록에 싣는다.
