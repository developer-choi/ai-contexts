# PR Comment Write

다른 사람의 PR에 코멘트를 달거나 코드 변경에 대해 질문·제안할 때, 내용이 맞는지 확인하고 말투를 다듬어주는 스킬입니다.

## 동기

PR 코멘트는 공개적이고 기록에 남습니다. 잘못된 지적은 신뢰를 떨어뜨리고, 날카로운 말투는 관계를 해칩니다.

PR 주소를 건네면 그 PR의 본문과 변경 내역, 이미 달린 코멘트를 읽고 남기고 싶은 의견을 받습니다.

그다음 코멘트를 올리기 전에 세 가지를 살핍니다.

- **PR 본문 대조**: 지적하려는 내용이 이미 PR 본문에 설명돼 있지 않은지
- **변경 범위 확인**: 지적하려는 코드가 이 PR에서 수정된 건지, 기존부터 있던 건지
- **기술적 정확성**: 지적이 틀렸거나 근거가 약하지 않은지

문제가 발견되면 코멘트를 작성하지 않고 먼저 알려줍니다.

단순한 수정 제안이 아니라 설계를 두고 나누는 이야기라면, 토론으로 먼저 정리할지 묻습니다.

구조를 어떻게 잡을지, 어떤 방식을 고를지, 무엇을 얻는 대신 무엇을 내줄지를 따지는 이야기가 여기에 해당합니다.

## 작성 방식

확인을 마친 내용은 두 단계로 정리합니다. 먼저 그 내용으로 코멘트 초안을 만들고, 그다음 초안의 말투와 구조, 분량을 다듬습니다.

다듬기는 초안 작성에 이어서 진행하고, 대화가 길어졌으면 앞부분을 정리한 뒤 넘어갑니다.

완성된 코멘트는 먼저 보여드리고, 확인을 받으면 제출합니다.
