# build-arms.mjs 사용법

`node <prompt-review 스킬 폴더>/benching/scripts/build-arms.mjs <명세> <출력루트> [묶음필터]`

비교군마다 원본 폴더를 `<출력루트>/<비교군 이름>`에 복사하고, 명세에 적힌 치환을 적용한다.
만든 폴더 경로를 `bench-ablation.mjs` eval-set의 `variant_cwds`에 넣는다.

## 인자

- `<명세>` 확장자가 `.mjs`·`.js`면 그 모듈의 default export를, 그 밖이면 JSON으로 읽는다
- `<출력루트>` 비교군 폴더를 만들 곳. 없으면 만든다
- `[묶음필터]` 쉼표로 구분한 묶음 이름. 묶음은 비교군 이름의 첫 `/` 앞 조각이다(`k1/w2`의 `k1`). 주면 그 묶음의 비교군만 다시 만들고 나머지 폴더는 건드리지 않는다

## 명세

```js
{
  src: '<원본 폴더 절대경로>',   // 읽기만 한다
  arms: {
    'k1/w1': [],                                      // 치환 없음(현행)
    'k1/w2': [
      { file: 'a/b.md', from: '원문', to: '치환문' },
      { file: 'a/b.md', line: '통째로 지울 줄' },     // from: line+개행, to: '' 과 같다
    ],
  },
}
```

- `file`은 `src` 기준 상대경로다
- `from`(또는 `line`+개행)은 그 파일에 정확히 1회 있어야 한다. 0회·2회 이상이면 멈춘다
- 한 비교군 안에서 같은 파일의 치환은 적힌 순서대로 이어서 적용된다

## 동작

- 비교군 폴더가 이미 있으면 지우고 다시 복사한다
- 치환 전에 복사본의 모든 `.md`를 LF 개행으로 맞춘다. 치환 없는 비교군도 같다

## 출력

비교군마다 stdout에 `<비교군>: <치환 수>건 치환, <파일 수>파일` 한 줄.

## exit code

- 0 모든 비교군을 만들었다
- 1 `<명세>`나 `<출력루트>`가 없다(사유와 이 문서 경로를 stderr에 출력한다). 또는 치환 항목에 `from`/`to`·`line`이 없거나 원문이 정확히 1회가 아니다(비교군·파일·횟수를 담은 예외). 그때까지 만든 비교군 폴더는 남는다
- 2 명세에 `src`·`arms`가 없거나 `src` 폴더가 없다
