# 시간과 순서

세션이 닫히면 **무엇이 오래 걸렸는지와 지시가 어떤 순서로 왔는지**가 함께 사라진다. 남는 것은 "오늘 좀 오래 걸렸다"는 체감뿐이라, 다음 세션도 같은 자리에서 같은 시간을 쓴다.

두 가지를 본다. 재료는 같은 표지만 읽어내는 것이 다르다.

- **왜 오래 걸렸나** — 시간이 몰린 자리가 내 판단이었는지, 오래 도는 도구였는지, 사용자 승인을 기다린 것이었는지
- **순서** — 같은 정정이 두 번 나온 자리, 전제가 뒤늦게 붙은 자리. 뒤에 온 것이 앞에 왔어야 했다면 그것은 다음에도 반복될 순서이므로 프롬프트로 내린다

## 1. 표를 뽑는다

```
node {{skill_dir}}/scripts/session-state.mjs timeline --session <session_id>
```

발화마다 시각·걸린 시간·시간을 먹은 자리를 붙여 낸다. 볼 것이 없는 세션은 스크립트가 「볼 것 없음」으로 끝내므로, 그때는 이 단계를 여기서 접는다.

시간은 기계가 알지만 **무엇을 시킨 것이었는지는 모른다.** 잘린 발화마다 요약을 붙여 json으로 적는다 — 스크립트가 낸 번호가 `rows`의 키다.

```json
{
  "title": "<날짜 · 레포 · 이번 세션이 한 일>",
  "rows": { "<번호>": "(무엇을 시킨 발화인지 한 줄)" },
  "time": ["<왜 오래 걸렸나>"],
  "order": ["<순서에서 보이는 것>"]
}
```

`time`·`order`는 표를 읽고 채운다. 마지막 줄에는 **다음에도 이 순서를 밟을 것인지와 어디에 심을 것인지**를 적는다 — 그게 없으면 표를 읽고도 무엇을 바꿀지는 매번 다시 생각하게 된다.

## 2. 열어서 본다

```
node {{skill_dir}}/scripts/session-state.mjs timeline --session <session_id> --notes <json 경로> --html \
  | node {{contexts}}/local-html-roundtrip.mjs open pre-exit -
```

채팅에 표를 늘어놓지 않는다 — 스무 줄이 넘어가면 훑어지지 않고, 이 산출물의 값은 훑어서 한눈에 몰린 자리가 보이는 데 있다. 한 번 읽고 버리므로 레포에 남기지 않는다.

## 3. 넘긴다

여기서 끝내지 않는다. 표는 재료고, 처리는 이미 있는 자리가 한다.
