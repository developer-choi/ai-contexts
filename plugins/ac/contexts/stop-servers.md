# stop-servers.mjs 사용법

`node <ai-contexts 배포 폴더>/contexts/stop-servers.mjs <list|stop> [<경로>…] [--worktrees] [--port <포트>]…`

스킬 문서에는 `{{contexts}}/stop-servers.mjs`로 적는다. 스크립트에서는 `findServers`·`stopServers`·`withWorktrees`를 import해 사용한다.

## 대상

경로와 포트를 섞어 줄 수 있고, 하나 이상 있어야 한다.

- `<경로>`: 그 경로(하위 경로 포함)를 명령줄에 담은 프로세스. `C:\a`·`C:/a`·`/c/a` 꼴을 모두 잡는다
- `--port <포트>`: 그 포트를 LISTEN 하는 프로세스. 여러 번 줄 수 있다
- `--worktrees`: 경로가 git 저장소면 거기서 뻗은 워크트리 경로도 대상에 넣는다

찾은 프로세스를 띄운 쪽(npm·npx·pnpm·yarn, `cmd /c`, `sh -c` 등)까지 거슬러 올라가 트리 꼭대기를 찾는다. 이 스크립트 자신과 그 조상은 대상에서 뺀다.

## 명령

- `list`: 끄지 않고 보여준다. exit 0
  - `[대상] …` 아래 `찾은 프로세스 N개`와 `끌 때 트리째 끄는 꼭대기 M개`를 `<pid> <이름> <명령줄>` 줄로 출력한다
  - 없으면 `없음 …`
- `stop`: 꼭대기마다 트리째 끄고 다시 조회한다
  - `닫음 …트리 N개(찾은 프로세스 M개)`와 끈 목록, exit 0
  - 끈 뒤에도 남은 것이 있으면 `✗ 끈 뒤에도 남은 프로세스 N개`와 그 목록, exit 1
  - 끌 것이 없으면 `이미 꺼져 있었음 …`, exit 0

명령줄에 상대경로만 적힌 서버(node에 파일 이름만 넘긴 것)는 경로로 안 잡힌다. 끈 뒤에도 폴더가 안 지워지면 삭제 성공으로 넘기지 말고, 포트로 다시 찾거나 보고한다.

## 실패

명령이 `list`·`stop`이 아니거나, 대상이 없거나, `--port` 뒤에 숫자가 없으면 사유와 이 문서 경로를 stderr에 출력하고 exit 1.
