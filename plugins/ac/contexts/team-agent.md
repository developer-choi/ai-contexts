# 팀/서브에이전트 운용 규칙

에이전트를 이름 있는 팀원으로 띄울지와 결과를 받는 법을 정한다.

## Claude Code

같은 상대에게 다시 보낼 일이 있는지, 결과를 누가 받는지에 따라 띄우는 방식을 고른다. 결과는 띄운 쪽이 기다리는 그 턴 안에 와야 한다.

- 결과를 받은 뒤 같은 상대에게 다시 보낼 단계(사용자 수정 반영·여러 라운드)가 있으면 **Agent** 호출에 `name`을 붙여 팀원으로 띄운다.
  - `name` 없이 띄운 에이전트도 spawn 결과의 agentId로 `SendMessage`를 보내면 이전 맥락을 지닌 채 재개되지만, agentId는 실행마다 바뀌어 절차 문서에 미리 적을 수 없다.
- 팀원 프롬프트에 **결과를 `SendMessage`로 `to: "main"`에 보내라**고 명시한다. 팀원의 평문 출력은 메인이 턴을 끝낸 뒤에야 대기 알림(`idle_notification`)에 실려 와, 명시하지 않으면 메인이 그 결과를 기다리는 턴 안에는 오지 않는다.
- 결과를 받아야 하는 쪽이 서브에이전트면 다시 보낼 단계가 있어도 `name` 없이 띄운다(다음 라운드는 위 agentId 재개). 누가 띄웠든 팀원이 보내는 것은 전부 메인 세션으로 가서, 서브에이전트가 띄운 팀원의 결과는 그 서브에이전트에게 돌아오지 않는다.
