# 콘텐츠 배치 정책 (대주제)

KA / MP / AC 어디로 갈지 결정하는 글로벌 분업 정책.

## 대주제 분업

| 프로젝트 | 자료 형태 | 판단 질문 |
|---------|----------|----------|
| KA (knowledge-archive) | 글 — 학습 정리, 코딩 팁 | "이게 뭐야? / 왜?" |
| MP (monorepo-playground) | 코드 — 예제코드 또는 MP 코드 직결 가이드 | "MP에서 이걸 어떻게 구현해?" |
| AC (ai-contexts) | 규칙·설정 | "공통 원칙이 뭐야?" |

## MP·KA 경계

코드 스니펫이 붙어 있어도 MP 코드와 무관하게 홀로 서는 설명은 KA다.
