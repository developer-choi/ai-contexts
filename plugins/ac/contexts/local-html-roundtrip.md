# local-html-roundtrip.mjs 사용법

`node <ai-contexts 배포 폴더>/contexts/local-html-roundtrip.mjs open <마커> <html경로|-> [--slug <슬러그>]`

스킬 문서에는 `{{contexts}}/local-html-roundtrip.mjs`로 적는다. 배포가 절대경로로 채운다.

HTML을 BOM 없는 UTF-8로 임시 폴더에 `<마커>-<슬러그>.html`로 저장하고, Windows 예약작업으로 기본 브라우저에서 연다. 브라우저가 실제로 떴는지까지 확인한다.

## 인자

- `<마커>`: 파일 이름과 예약작업 이름에 들어간다. 영숫자로 시작하고 영숫자·하이픈·밑줄만 쓴다
- `<html경로>`: 열 HTML 파일. `-`이면 표준입력에서 읽는다
- `--slug <슬러그>`: 파일 이름 뒷부분. 영숫자로 시작하고 영숫자·점·하이픈·밑줄만 쓴다. 기본값은 현재 시각(밀리초)
- `--help`·`-h`: 이 문서를 stdout에 출력하고 exit 0

## 출력

- 성공하면 연 HTML의 절대경로 한 줄을 stdout에 출력하고 exit 0
- 폼에 채운 값은 되받지 않는다. 사용자가 폼의 [복사하기]로 복사한 JSON을 채팅에 붙여넣는다

## 실패 (모두 stderr, exit 1)

- 서브커맨드가 없거나 모르는 것, 마커·슬러그 꼴이 틀림, HTML 경로 없음: 사유와 이 문서 경로
- HTML을 못 읽음: 경로와 오류
- 예약작업이 브라우저를 못 띄움: 사유와 `열려던 파일: <경로>`. 사용자가 그 경로를 브라우저로 직접 열면 내용은 그대로 볼 수 있다
  - 등록됐지만 돌지 않음(배터리 등)
  - 15초 안에 안 끝남
  - 브라우저를 여는 명령이 0이 아닌 코드로 끝남
  - 예약작업 등록·실행 자체가 막힘
