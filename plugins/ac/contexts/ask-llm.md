# ask-llm.mjs 사용법

`node <plugins/ac/contexts 폴더>/ask-llm.mjs --vendor <벤더> [--schema <스키마 경로>] <보낼 내용 경로|->`

스킬 문서에 이 경로를 적는 꼴은 배포 규약의 [plugin 스킬](../../../meta/deploy-conventions.md#plugin-ac로-옮긴-스킬hookcontexts)·[레포 로컬 스킬](../../../meta/deploy-conventions.md#레포-로컬-스킬-claudeskills-커밋) 절을 따른다.

다른 회사 LLM에 프롬프트 하나를 보내고 답만 받아 온다. 대화는 이어지지 않아서, 앞서 물은 내용이 필요하면 보낼 내용에 다시 넣는다.

받는 모델은 도구를 사용하지 못한다. 명령 실행·파일 읽기·쓰기·웹 검색이 모두 막혀 있어서, 판단에 필요한 자료는 보낼 내용 안에 다 넣는다.

답은 100초까지 기다린다. 오래 걸릴 일이면 처음부터 따로 답할 수 있는 질문 여러 개로 쪼갠다.

## 인자

- `--vendor <벤더>`: 받을 회사. 지금은 `gemini`만 있다
- `<보낼 내용 경로>`: 보낼 프롬프트 전체가 든 파일. `-`이면 표준입력에서 읽는다
- `--schema <스키마 경로>`: 답을 JSON으로 받아야 할 때만 준다

## 출력

- 성공하면 답 본문을 stdout에 출력하고 exit 0
- `--schema`를 줬으면 스키마에 맞춘 JSON 한 줄을 출력한다

## 실패

실패하면(시간 초과 포함) 사유를 stderr에 출력하고 exit 1로 끝난다. 사유를 사용자에게 보이고 멈춘다. 그 일을 직접 해 버리면 사용자는 다른 회사 모델이 사용되지 않았다는 것을 알 수 없다.
