# 크롬 조작에서 막히는 자리

- **입력**: `computer type`은 한글·공백·영문을 깨뜨린다.
  - 입력창(contenteditable)에 focus를 주고 `document.execCommand('insertText', false, 텍스트)`로 넣은 뒤, `innerText`가 원문과 같은지 확인하고 보내기 버튼을 누른다.
  - 웹이 일하는 중이면 Ctrl+Enter로 대기열에 넣는다.
- **응답이 끝났는지 판단**: 페이지 텍스트에 "응답 중입니다"·"작업 중…"·"실행 중"이 있으면 아직 진행 중이다. 진행 중 여부만 JS로 받고, 끝난 뒤 마지막 응답을 한 번 읽는다. 한 번 기다리는 시간은 45초를 넘기지 않고 대기 묶음 하나에 대기는 하나만 둔다. 넘으면 CDP 시간 초과로 끊긴다. 대기 상한은 대기 호출 40번(약 30분)이다.
- **숨은 탭**: 조작하는 탭이 뒤에 있으면 렌더링이 멈춘다. 읽기·JS 실행 전에 스크린샷을 한 번 찍어 깨운다.
- **휴대폰 폭**: 창은 Windows 최소 폭(페이지 500)에서 멈춘다. 휴대폰 폭은 그 폭의 iframe에 같은 페이지를 띄워 잰다.
