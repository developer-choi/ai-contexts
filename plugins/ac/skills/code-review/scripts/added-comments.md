# added-comments.mjs 사용법

`<diff 명령> | node <code-review 스킬 폴더>/scripts/added-comments.mjs` 또는 `node <code-review 스킬 폴더>/scripts/added-comments.mjs <diff 파일>`

unified diff(`git diff <base>...<head>` 등)를 표준입력이나 파일로 받아, 새로 추가된 주석 후보를 표로 출력한다. 옵션은 없다.

- 대상은 `.js`·`.jsx`·`.ts`·`.tsx`(`.cjs`·`.mjs` 등 포함)·`.css`·`.scss`·`.less`·`.vue`·`.svelte` 파일이다
- 후보는 추가 줄 중 `//`·`/*`·`*/`·`<!--`·`-->`가 들었거나 `*`로 시작하는 줄이다. 블록 주석은 한 행으로 묶는다. 주석이 아닌 줄도 섞여 나오므로 행마다 판정한다

## 출력

- `| # | 위치 | 주석 원문 | 판정 |` 표. 위치는 `<파일>:<새 파일 줄 번호>`이고, 판정 칸은 리뷰어가 채운다
- 후보가 없으면 `추가된 주석 후보 없음`. 대상 밖 파일이 있으면 그래도 표 머리를 찍는다
- `주석을 뽑지 않은 파일 N개: …` 줄이 나오면 그 아래 안내대로 한다
  - 파일마다 허용 목록 규칙이 그 파일 종류에 걸리는지 본다
  - 걸리면 그 파일의 diff를 직접 읽어 추가된 주석을 같은 표에 행으로 넣고, 위치 칸 끝에 `(직접 추출)`을 붙인다
  - 안 걸리면 사유를 표 위에 한 줄 적는다

## 실패

- 입력에 `diff --git ` 줄이 없으면(앞 diff 명령이 실패해 빈 입력이 온 경우 포함) `diff 입력이 비었다 …`와 이 문서 경로를 stderr에 출력하고 exit 1. diff 명령을 바꿔 다시 돌리지 말고, 받은 명령과 이 오류를 그대로 보고한다
- diff 파일을 못 읽으면 사유와 이 문서 경로를 stderr에 출력하고 exit 1
