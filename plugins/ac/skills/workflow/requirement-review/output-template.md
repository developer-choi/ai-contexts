# 페이지 리뷰 산출물에 담을 것

형식은 자유다. 아래 내용이 빠지지 않으면 된다.

## global.md

- 서비스·기능 개요(무엇을 하는 서비스인지, 이 기능의 목적, 대상 사용자, 핵심 플로우)
- 여러 페이지가 함께 쓰는 컴포넌트·로직·엣지케이스
- 반응형 정책, 비기능 요구사항
- 여러 페이지에 걸친 질문

## page.md (페이지마다)

- URL과 역할, 그 페이지에 딸린 모달, 타이틀·OG 같은 메타
- 쓰는 API(기존·수정·신규, 주고받는 필드)와, API마다 로딩·에러·성공일 때 화면
- 페이지·컴포넌트 동작(상황별 결과, 엣지케이스, 빈 상태, 이 페이지만의 반응형 차이)
- 재사용하는 컴포넌트와 새로 만들 컴포넌트(구조 관찰)
- 기획자·디자이너에게 물을 질문(사용자가 판단하지 못한 것 포함)

## layout.md (여러 페이지가 공유하는 레이아웃이 있을 때)

- 적용 페이지, 고정 영역 배치, 레이아웃에 든 공통 UI, 메타
