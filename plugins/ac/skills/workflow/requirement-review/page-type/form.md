# 폼 페이지

사용자 입력이 주요 인터랙션인 페이지에 추가 적용한다.

## 포커스

- 페이지에 들어왔을 때 첫 입력 필드에 포커스를 두는가?

## 입력 유효성 검증

- 필수/선택 필드 구분이 되어 있는가?
- 각 필드의 타입과 포맷이 정의되어 있는가? (문자열 길이, 숫자 범위, 날짜 형식 등)
- 클라이언트 검증과 서버 검증의 범위가 구분되어 있는가?
- 검증 실패 시 에러 메시지가 정의되어 있는가?

## 이탈 보호

- 저장하지 않은 입력이 있을 때 페이지를 떠나면(뒤로가기·취소·링크 이동·탭 닫기) 경고하는가?
- 떠났다가 돌아오면 입력값이 남는가, 초기화되는가?

## 제출

- 폼 제출 실패 시 입력값이 유지되는가?
- 같은 제출이 두 번 실행되는 것을 막는가?

## 환경

- 모바일 키보드가 올라올 때 레이아웃이 어떻게 되는지 정의되어 있는가?
