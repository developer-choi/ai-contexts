# URL / 라우팅 점검 가이드

## 1. URL 설계

- 각 페이지의 URL 경로가 정의되어 있는가?
- URL만 보고 어떤 페이지인지 유추할 수 있는가?
- URL 계층 구조가 페이지 간 관계를 반영하는가?
- 동적 파라미터(`:id` 등)가 필요한 페이지는 식별되어 있는가?
- 동적 파라미터에 올 수 있는 값이 명세되어 있는가?
- 동적 값이 pathname에 있어야 하는지 쿼리스트링에 있어야 하는지 근거와 함께 검토했는가?
  - 공유·북마크·SEO 대상이면 pathname이 우선 후보
- URL 공유/북마크 시 의미 있는 페이지가 보이는가?
- 페이지 타이틀과 공유 시 노출(OG 타이틀·설명·이미지)이 정의되어 있는가?

## 2. 페이지(라우트) 분리 판단

화면이 별도 라우트로 존재해야 하는지 다음을 점검한다. 모두 "아니오"면 별도 라우트가 아니라 컴포넌트 상태로 처리한다.

- 뒤로가기 했을 때 이 화면이 나와야 하는가?
- URL을 직접 입력해 진입했을 때 이 화면이 나와야 하는가?
- 새로고침 했을 때 이 화면이 유지되어야 하는가?

## 3. 중첩 라우트 / 레이아웃

- 중첩 라우트가 필요한 구간이 있는가?
- 레이아웃 내 공통 UI 요소(네비게이션, 브레드크럼 등)가 식별되어 있는가?
