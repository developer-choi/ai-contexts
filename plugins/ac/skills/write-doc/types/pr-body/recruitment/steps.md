# pr-body recruitment — subtype마다 더 도는 절차

## [RECEIVE_STEP] 재료 받기

게시한 PR을 다시 다듬는 중이면(pr-body 「재료 받기」의 게시본 경로) 게시본이 출발점이라 건너뛴다.

재료를 읽은 뒤 이 PR의 성격으로 주제를 식별하고, [완성본 라이브러리](../../../../../contexts/writing-guide/types/pr-body/recruitment/library/)(주제별로 미리 써 둔 PR 본문)를 글롭해 맞는 완성본을 찾는다. 있으면 그 파일을 고쳐 쓸 예전 글로 삼아 출발점으로 쓴다. 이번에 안 한 항목·섹션을 빼고 과제 고유 값을 채운다.
