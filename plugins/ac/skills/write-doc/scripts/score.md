# score.mjs 사용법

`node <write-doc 스킬 폴더>/scripts/score.mjs <산출물.md> [옵션]` 또는 `… score.mjs --rules`

글을 객관(분량 등)과 반객관(기계 매칭 위반)으로 따로 채점해 stdout에 출력한다. 줄 번호 `L`은 frontmatter를 포함한 파일 기준이다.

## 모드

- `<산출물.md>`: 전체 채점. 끝에 `>> 기계 적발 합계(참고용, 점수 아님): N건 + 눈으로 확인 후보 M건(…)`. exit 0
- `--rules`: 무엇을 잡는지(낱말·경고 항목·대체어) 출력한다
- `<산출물.md> --structure`: 긴 문단·개수 선언 뒤 리스트 없음만 출력한다. 톤을 다듬기 전, 내용을 채운 초안의 나눔만 볼 때 쓴다
- `<산출물.md> --residual`: 남은 `[//]: #` 주석만 본다. 있으면 exit 1, 없으면 exit 0. 발행 직전 확인용

## 전체 채점 옵션

- `--props <명제리스트.txt>` 한 줄에 핵심 명제 하나. 본문에 그대로 들어 있는지만 본다
- `--tokens <N>`·`--turns <N>` 세션에서 얻은 값. 출력의 `객관 (자동 계측)` 절에 기록만 한다
- `--json` 사람용 출력 끝에 기계용 `@@score {total,titleHits,refHits}` 한 줄을 추가한다(발행 스크립트가 읽는다)

산출물 경로가 없으면(`--rules` 밖) 사유와 이 문서 경로를 stderr에 출력하고 exit 1.
